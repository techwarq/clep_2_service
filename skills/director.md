# Clep director playbook (read for every video)

Code has already done the directing: it picks scenes, times them, moves the camera, sets transitions,
applies the brand, and wrote a SEED draft from the site's own copy. You only write the words and
choose the order of beats. The seed is already valid. Keep any line you can't clearly beat.

## Copy rules
1. **Use their words.** Take product nouns, verbs and claims from SITE COPY and tighten them. Don't add facts.
2. **No invented proof.** Never make up numbers, customers, logos, quotes, prices or dates. If a slot wants
   one and neither the site nor the user gives it, keep the seed. Code strips invented ones anyway.
3. **Short.** Headlines ≤ 8 words. List items 2–4 words, each starting with a verb or noun. Respect every
   character limit. Anything over gets cut automatically, mid-thought.
4. **Concrete beats clever.** "Clips from your code" beats "Unleash your potential". Banned: unleash,
   supercharge, revolutionize, seamless, cutting-edge, next-level, game-changer, empower, elevate.
5. **Accent = payoff words.** An accent must be an exact substring of its headline, usually the last 1–3 words.
6. **One thread, one idea per beat.** Open on the viewer's pain rather than the product's promise. Then comes the turn (the product is
   used), then the product working, then one payoff, then the name. See the story playbook when it's loaded.
7. **CTA is a real button.** Prefer the site's own button text ("Ask for invite", "Start free"). 2–3 words,
   no arrows or emoji.

## Good vs bad
| Slot | Bad | Good |
|---|---|---|
| hook | "Supercharge your demos with AI-powered magic" | "Product demos, straight from your code." |
| opener | "Introducing Acme, the all-in-one finance platform" | "Profit dropped. Nobody knows why." |
| list item | "Seamless integration with all your favorite tools" | "Tag it in code" |
| end headline | "The future of video is here!" | "Start creating for free." |
| cta | "Click here to learn more →" | "Ask for invite" |

## Editing
Change only what the user asked for. Every other value stays identical. "Punchier" means fewer and
shorter words, not new claims.

## Looks
If the context has APPLIED LOOK, code already restyled the video: say it in one short clause
("in an anime style"). Describe only what that look lists. If it says NOT POSSIBLE YET or COULD
NOT BE BUILT, say so plainly. Never claim a visual style the context doesn't list.
